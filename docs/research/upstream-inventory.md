## Expression-test corpus

Location: `src/tests/Microsoft.PowerFx.Core.Tests.Shared/ExpressionTestCases/` (416 `.txt` files, **22,047 cases**).
Consumed by the interpreter tests (`FileExpressionEvaluationTests`) and by Core tests.

Format (implemented in `packages/test-suite/src/txt-format.ts`):

- `>> expression`; continuation lines start with a space; next non-comment line is the expected result.
- Header directives: `#SETUP:` (flags/handlers, `disable:` prefix, `PowerFxV1` aggregate expands to 11
  features), `#DISABLE: file`, `#OVERRIDE: file`. `#DISABLE.NET:` gates C# runtimes only; ignored.
- Files can start with a doubled UTF-8 BOM (`Dec2Hex.txt`).
- Expected results are compact serialized expressions: `Table({Value:1})`, `Blank()`, `Date(2020,1,1)`,
  `Error({Kind:ErrorKind.Div0})`, `Errors: Error 0-3: msg|Error ...` (compile errors), `#SKIP`, `#NoValue`.
- Comparison is by exact string, with exceptions in upstream `BaseRunner.RunAsync2` (date/datetime
  tick tolerance, float tolerance via `NumberCompare`, Decimal→Number message rewriting, `Error*`
  expectations re-run as `IsError(...)`). **Only exact match, `#SKIP` and compile-error matching are
  implemented so far.**

Top expected-result shapes: numbers (~4k), strings (~2.7k), booleans (~4.3k), compile errors (~2.9k),
`Error({Kind:...})` (~2.5k), tables (~1k), `Blank()`, dates/datetimes.

### Applicability

Upstream runs the corpus under profiles (`FileExpressionEvaluationTests`). We mirror these as
`PROFILES` in `packages/test-suite/src/profile.ts`:

| Profile      | Setup                                                                   |
| ------------ | ----------------------------------------------------------------------- |
| `v1-decimal` | `PowerFxV1,disable:NumberIsFloat,DecimalSupport` (Power Fx 1.0 default) |
| `v1-float`   | `PowerFxV1,NumberIsFloat,DecimalSupport`                                |

Current report (placeholder engine, so everything is unsupported): `v1-decimal` has 16,173 applicable
cases (5,874 not applicable); `v1-float` 14,959. Reports are generated by
`pnpm --filter @powerfx-ts/test-suite compat <profile>` into `packages/test-suite/reports/`.

Roughly 19.7k of 22k cases need no runner-side handler. Handlers required by the rest (case counts):
`AllEnumsSetup` 845, `AllEnumsPlusTestEnumsSetup` 438, `AllEnumsPlusTestOptionSetsSetup` 432,
`EnableExpressionChaining` 258 (parser flag), `MutationFunctionsTestSetup` 172, `DisableMemChecks` 172,
`TextFirst` 76 (parser flag), `TraceSetup` 30, `OptionSetTestSetup` 23.

## Dependency graph for the first slice

`Lexer → Parser (+ParserOptions) → Syntax tree → Binder (types, symbols, function table) → IR →
EvalVisitor (values)`. Upstream Core is large because Texl functions, entities, delegation and
display names are interleaved; the slice needs only literals, identifiers, unary/binary ops,
`If`, primitive types and values.
