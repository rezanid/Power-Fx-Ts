# Provenance register

Every file or test corpus derived from Microsoft Power Fx is recorded here.

**Pinned upstream commit:** `df4ceba5e08220db670c25afead342ce699c50b5` (2026-10-02)

No upstream code has been copied. Diagnostic message templates PFX2001–PFX2006 and PFX2024–PFX2028
reuse the English wording of upstream `src/strings/PowerFxResources.en-US.resx` (MIT, Copyright
Microsoft Corporation) so compile-error expectations match; the binder, evaluator and number
formatting are original,
informed by corpus behavior and `BaseRunner.cs`. The test-suite reader (`packages/test-suite/src/txt-format.ts`,
`profile.ts`, `runner.ts`) is an original implementation of the upstream `.txt` format and applicability
rules, informed by `TestRunner.cs` and `BaseRunner.cs`.

`docs/research/scalar-text-probes/`, `packages/engine/test/fixtures/scalar-text-probe.*.tsv`, and
`docs/research/scalar-text-before-after.cases.tsv` contain reference probe or comparison data
generated from the pinned `Len.txt`, `Lower.txt`, and `Upper.txt` corpus and harness.
`docs/research/dropcolumns-probes/` and
`packages/engine/test/fixtures/dropcolumns-probe.*.tsv` contain reference-generated `DropColumns`
probes from the pinned PowerFxV1 implementation and expression corpus. No upstream implementation
code or test data is copied.
`packages/engine/test/fixtures/showcolumns-*.tsv` contains pre-implementation reference probes for
`ShowColumns`. The dedicated `showcolumns-probe` harness command records type-field order, direct
runtime field enumeration, serialized output, and diagnostics including warning severity.
`docs/research/renamecolumns-probes/` and `packages/engine/test/fixtures/renamecolumns-*.tsv`
contain pre-implementation probes for `RenameColumns`, including independently captured schema
order, runtime field enumeration, serialization, diagnostics, and the repeated-source runtime
exception deviation.
`docs/research/addcolumns-probes/` and `packages/engine/test/fixtures/addcolumns-*.tsv` contain
pre-implementation `AddColumns` probes, including original-row scope, aliases, outer-variable
shadowing, left-to-right additions, skipped Blank/Error rows, invalid dotted identifiers and
independently captured schema/runtime/serialization ordering.
`docs/research/table-selection-probes/` and
`packages/engine/test/fixtures/table-selection-{boundary,casts}.*.tsv` contain pre-implementation
FirstN/LastN count-boundary probes. They separately capture formula results and direct unchecked
Int32 casts with exact runtime metadata. Overflow observations are runtime-dependent; the proposed
portable conversion rule is not yet accepted. No upstream implementation code is copied.
`packages/interpreter/src/functions/text-case-map.ts` is generated from installed .NET
`CultureInfo("en-US").TextInfo` behavior used by pinned `LibraryText.cs`; the harness verifies every
Unicode scalar before generation and when validating the committed snapshot. No upstream
implementation code or test data is copied. Exact commands, source paths, runtime provenance, and
the refresh caveat are recorded in `docs/research/scalar-text-probes/README.md`.
